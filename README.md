# indicium-adapters-agentic-ai

Agentic-AI `DomainAdapter` for the indicium ecosystem: classification vocabulary
and claim/ontology enrichment for language-model agents, multi-agent systems,
tool use, reasoning, and the engineering stack around them.

```python
from indicium_adapters_agentic_ai import AgenticAIAdapter

adapter = AgenticAIAdapter()
adapter.enrich_claim({"subject": "large language model"})
# {'subject': 'large language model',
#  'ontology_terms': {'subject': 'WD:Q115305900'},
#  'ontology_term_justifications': {'subject': 'semapv:LexicalMatching'},
#  'ontology_term_sources': {'subject': 'Wikidata'}, ...}
```

## Why two vocabularies

The sibling astronomy adapter needs one source, because astronomy has a living
curated thesaurus that covers its own subject matter. This domain has none.

Its curated vocabulary — the ACM Computing Classification System — froze in
2012, which is before the subject matter existed. Measured against 35 terms
drawn from representative papers of the corpus wave, CCS 2012 matches 15, and
every miss is a term coined after it froze: large language model,
chain-of-thought prompting, retrieval-augmented generation, in-context learning,
tool calling, instruction tuning, RLHF.

So the index ships both:

| source | role | concepts |
|---|---|--:|
| ACM CCS 2012 (SKOS) | curated spine, frozen | 2,113 |
| Wikidata (subclass closure of 15 anchors) | the layer coined since | 408 |

2,521 concepts, 2,813 lookup labels. CCS wins a label collision, because a
curated thesaurus outranks a crowd-maintained one where both have an entry.
`ontology_term_sources` records which answered, because the two do not carry the
same authority.

`subdomains` (13) and `techniques` (154) are read from the ACM's own tree — the
children of *Artificial intelligence* and *Machine learning*, and everything
below them — rather than hand-listed.

## An anchor is verified before it is used

An exact label match against a published vocabulary can still be the wrong
sense. Wikidata's "tool use" (Q12333059) is a facet of animal behaviour and
human sociology; rooting a subclass closure there would pull primatology into an
agent adapter under a confident-looking CURIE. Anchors checked and refused are
recorded with their reason in the index provenance, so the next person to reach
for one finds the reason rather than repeating the mistake.

## How much of the field it reaches

`coverage.json`, regenerated by `scripts/measure_coverage.py`, is the evidence:
800 recent arXiv papers drawn from the corpus wave's own queries, every
multiword title phrase appearing in at least three of them.

**19 of 152 frequent phrases resolve (12%)** — 11 through Wikidata, 8 through
CCS.

That number is low and it is the honest one. The unresolved list is the useful
half of the output, because it is not noise: `llm agents`, `multi-agent
framework`, `self-evolving agents`, `agent harness`, `agent skills`, `coding
agents`, `prompt injection`, `agent memory`. This field's working vocabulary is
compositional and newer than anything that publishes a thesaurus — bare "agent"
resolves in neither source. A term in neither is written to
`ontology_terms_unmatched` rather than passed over, so "not in either
vocabulary" stays distinguishable from "not attempted", and the gap list feeds
the next release.

Concept coverage is one of four things the adapter does. The other three do not
depend on it: `primary_domain` stops these papers classifying as *other*, the 29
domain qualifiers reach the extraction prompt, and the CCS tree supplies the
classification vocabulary.

## Qualifiers

29, in six groups: what the system is built out of (`built_on`,
`prompted_with`, `fine_tuned_on`, …), how the agents are arranged
(`orchestrated_by`, `delegates_to`, `invokes_tool`, `retrieves_from`, …), how it
reasons (`reasons_by`, `decomposes_into`, `verified_by`, …), how it changes
itself (`evolves_via`, `selects_by`, `mutates`, `bootstrapped_from`), how it is
judged (`evaluated_on`, `measured_by`, `compared_against`, `ablated_by`, …), and
where it stops (`constrained_by`, `fails_by`, `scales_with`).

Every one is snake_case, because Perspicacité routes adapter qualifiers onto the
open `asb:domainQualifier` slot whose SHACL shape enforces that pattern.

## Scope

Tier-3 only, per ADR 0001: classification vocabulary and claim enrichment. It
deliberately does **not** recognise repository accessions — those belong to the
canonical accession table in `asb-domain-core`, and a second copy here would be
the duplicate-then-drift failure ADR 0001 exists to prevent.

## Regenerating

```bash
python scripts/generate_concept_index.py          # network; writes _concept_index.json
python scripts/measure_coverage.py --papers 100 --min-papers 3 --out coverage.json
```

Nothing else in the package touches the network; `enrich_claim` is pure.
